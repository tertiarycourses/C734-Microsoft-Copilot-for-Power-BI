## Lab Activities

The 9 labs form one connected practical journey. Complete them in order so each verified output can support the activities that follow.

| # | Activity | Outcome |
|---:|----------|---------|
| **1** | [Enable Copilot and Set Up Your Power BI Environment](labs/lab-01-enable-copilot-and-set-up-your-power-bi-environment.md) | Confirm the licensing and tenant settings Copilot needs, and verify the Copilot pane appears in Power BI Desktop and the Service. |
| **2** | [Connect and Prepare Data So Copilot Can Understand It](labs/lab-02-connect-and-prepare-data-so-copilot-can-understand-it.md) | Load the Contoso Coffee dataset, shape it in Power Query, and give tables and columns clear names, correct types and relationships so Copilot can interpret the model. |
| **3** | [Write Effective Prompts in Power BI Desktop and the Service](labs/lab-03-write-effective-prompts-in-power-bi-desktop-and-the-service.md) | Open the Copilot pane on your model and write clear prompts that name the fields, metric, breakdown and intent, comparing a vague prompt with a specific one. |
| **4** | [Generate Report Pages from Prompts](labs/lab-04-generate-report-pages-from-prompts.md) | Use Copilot to generate a complete report page of related visuals from a single prompt, and to suggest content when you are unsure where to start. |
| **5** | [Refine Visuals and Layouts with Copilot](labs/lab-05-refine-visuals-and-layouts-with-copilot.md) | Use Copilot to change visual types, swap and sort fields, apply filters, and tidy the page layout without leaving the pane. |
| **6** | [Add Narrative Visuals and AI Summaries with Storytelling and Formatting](labs/lab-06-add-narrative-visuals-and-ai-summaries-with-storytelling-and.md) | Add a Copilot narrative (smart) visual, generate an AI page summary, and apply storytelling and formatting best practice to the report. |
| **7** | [Generate and Explain DAX Measures with Copilot](labs/lab-07-generate-and-explain-dax-measures-with-copilot.md) | Use Copilot to write DAX measures from plain-language descriptions, explain an unfamiliar measure, then name, format and validate each one. |
| **8** | [Set Up Q&A and Natural-Language Queries](labs/lab-08-set-up-q-and-a-and-natural-language-queries.md) | Add a Q&A visual, ask natural-language questions of the model, and improve accuracy by teaching Q&A synonyms and reviewing suggested questions. |
| **9** | [Summarise Insights and Share Your AI-Assisted Report and Dashboard](labs/lab-09-summarise-insights-and-share-your-ai-assisted-report-and-das.md) | Use Copilot to produce an executive insight summary, publish the report to the Service, pin a dashboard, and share it safely with the right people. |

## About

This repository contains the complete lab and courseware package for **Copilot for Power BI** (**C734**) by Tertiary Courses / Tertiary Infotech. The practical activities build progressively from **Enable Copilot and Set Up Your Power BI Environment** to **Summarise Insights and Share Your AI-Assisted Report and Dashboard**, with explicit checks that help learners verify each result before moving on.

### What you'll learn

- Complete **9 connected hands-on activities** and carry their outputs through one coherent learning journey.
- Practise with **Microsoft Copilot · Power BI · Microsoft Excel** and the supporting resources supplied in the repository.
- Begin with **Enable Copilot and Set Up Your Power BI Environment** and finish with **Summarise Insights and Share Your AI-Assisted Report and Dashboard**.
- Apply safe data handling, evidence checks and named human review before using AI-generated or automated outputs.

## Getting Started

### Prerequisites

- The accounts and software required for **Microsoft Copilot · Power BI · Microsoft Excel**. Follow the setup and access notes in each lab.
- Review [`labs/tools.md`](labs/tools.md) before class for environment, account and safe-use requirements.
- A modern web browser and Git for cloning the materials.
- Synthetic or authorised data only. Do not place secrets, personal data or confidential material into an unapproved service.
- A named human reviewer for facts, calculations, decisions and any externally released output.

### 1. Clone the repository

```bash
git clone https://github.com/tertiarycourses/C734---Copilot-for-Power-BI.git
cd C734---Copilot-for-Power-BI
```

### 2. Open the lab index

Start with [labs/README.md](labs/README.md), then complete Labs 1–9 in order. Each lab provides the activity context, practical steps and a way to verify the result.

### 3. Keep your connected outputs

Store each lab output in the suggested working folder and retain the evidence or review notes requested by the lab. Later activities depend on these approved outputs.
