# C734 — Copilot for Power BI

Build reports the fast way. This one-day, hands-on course teaches you to use **Microsoft Copilot
inside Power BI** — in Power BI Desktop and the Power BI Service on Microsoft Fabric — to turn
plain-language prompts into report pages, visuals, DAX measures and natural-language analysis.

## Course Information

- **Course Code:** C734
- **Course Title:** Copilot for Power BI
- **Duration:** 1 day
- **Level:** Beginner
- **Mode:** Instructor-led, hands-on practical labs
- **Course Registration:** [Copilot for Power BI](https://www.tertiarycourses.com.sg/copilot-for-power-bi.html)

## One Connected Project

Every lab adds one piece to a single, growing Power BI report — a Sales & Operations dashboard for
a fictional coffee retailer, **Contoso Coffee**. You enable Copilot and prepare the data in Labs 1–2,
build and refine the report with prompts in Labs 3–6, add AI-assisted DAX and natural-language
analysis in Labs 7–8, and publish and share the finished dashboard in Lab 9. Wherever possible you
use your **own** business data; a Contoso Coffee sample dataset is supplied for anyone who prefers
not to use real data.

There is **no assessment** — this is a commercial short course. Each lab proves itself with an
explicit *Test it* verification step instead.

## What You'll Learn

| Topic | Coverage |
|---|---|
| **01 — Get Started with Copilot in Power BI** | What Copilot for Power BI and Microsoft Fabric are; licensing, requirements and enabling Copilot; Copilot in Desktop vs the Service; effective prompting; connecting and preparing data |
| **02 — Create Reports and Visuals with Copilot** | Generating report pages from prompts; refining visuals and layouts; narrative visuals and AI summaries; formatting and storytelling best practice |
| **03 — AI-Assisted Data Modeling and Analysis** | Generating and explaining DAX measures with Copilot; setting up Q&A and natural-language queries; summarising insights; sharing AI-assisted reports and dashboards |

## Learning Outcomes

1. Explain what Copilot for Power BI and Microsoft Fabric are, and confirm the licensing and settings needed to enable Copilot.
2. Connect and prepare data so that Copilot can interpret it, and write effective prompts in Power BI Desktop and the Service.
3. Generate complete report pages and visuals from prompts, then refine their type, layout and formatting with Copilot.
4. Add narrative visuals and AI summaries, and apply storytelling and formatting best practice to a report.
5. Generate and explain DAX measures with Copilot to answer business questions.
6. Set up Q&A and natural-language queries so users can ask questions of the data in plain English.
7. Summarise insights, answer business questions, and publish and share an AI-assisted report and dashboard.

## Prerequisites

- Basic computer proficiency.
- Familiarity with tabular data (spreadsheets); prior Power BI experience is helpful but not required.
- A Copilot-enabled Power BI environment is provided for the labs (a paid Fabric capacity or Power BI Premium with the Copilot tenant switch on).
