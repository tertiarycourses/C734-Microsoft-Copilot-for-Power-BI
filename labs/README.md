# Labs — Microsoft Copilot for Power BI (C734)

**Course Code:** C734  |  **Version v2.0 · 4 October 2026**

All 9 labs build one connected **Contoso Coffee report**, which you begin in Lab 1 and complete in Lab 9. Wherever possible, use your own business data; a Contoso Coffee sample dataset is provided for anyone who prefers not to use real data. There is **no assessment** — each lab verifies itself with a 'Test it' step.
